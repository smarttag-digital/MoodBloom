# 🌸 MoodBloom — Diário de Humor

Um diário de humor digital, desenvolvido para registrar emoções do dia a dia, adicionar anotações pessoais e acompanhar os registros por meio de um resumo mensal com gráfico.

## ✨ Funcionalidades

- 😊 Seleção entre 9 opções de humor.
- 📝 Registro de anotações pessoais.
- 💾 Salvamento dos registros no navegador usando `localStorage`.
- 📅 Histórico com data e horário dos registros.
- 🌷 Resumo mensal com a quantidade de registros por humor.
- 📊 Gráfico visual para acompanhar as emoções.
- 🎀 Interface com cores pastel em rosa e lilás.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilos e identidade visual.
- JavaScript — interatividade, registros e gráficos.
- Git e GitHub — versionamento e hospedagem do código.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `templates/index.html` no navegador.

**Observação:** os registros são armazenados no `localStorage` do navegador. Eles não são sincronizados entre dispositivos e podem ser perdidos se os dados locais do navegador forem apagados.

O MoodBloom faz parte da minha jornada de aprendizado em tecnologia e desenvolvimento de software, com foco na prática de HTML, CSS e JavaScript.
